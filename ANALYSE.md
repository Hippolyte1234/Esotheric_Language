On se rend compte ainsi que ce code a sûrement des milliers de manières d'être écrit et que contrairement à l'humain, Gemini ne pense pas à l'aspect esthétique du code, mais justement plutôt à l'aspect puriste

Voici quelques points sur lesquels on peut clairement voir la différence entre le code d'un humain et celui d'un LLM:

Philosophie syntaxique:
- Mon code: Poetic / Ballad Style (littéraire, métaphorique)
- Code du LLM: Imperative / Scripting Style (déclaratif classique)

Noms de variables:
- Mon code: Noms thématiques : Jolene, Tommy, Milou, Midnight, Content, Desperation
- Code du LLM: Noms mathématiques explicites : alpha, beta, Delta, LinearSol, TwoA

Assignation des constantes:
- Mon code: Poetic number literals (Tommy is so handsome compte de lettres: 2, 8 = 28)
- Code du LLM: Littéraux numériques directs (Let Counter be 20, 2, 4)

Opérateurs arithmétiques:
- Mon code: Mots-clés idiomatiques : without (-), over (/), times (*), taking (appel)
- Code du LLM: Mots-clés fonctionnels : plus, minus, times, over



    Conclusion
p respecte pleinement la philosophie première d'un langage ésotérique comme Rockstar : transformer du code en paroles de chanson où l'algorithme est camouflé derrière la poésie. p' trahit l'esprit du langage en écrivant du pseudocode Basic/Python déguisé avec des mots-clés Rockstar.

Cette expérience met en lumière la dichotomie entre la sémantique d'un algorithme (l'invariant mathématique qu'on veut calculer) et sa matérialisation textuelle :

Un LLM tend à projeter les structures des langages dominants (noms analytiques, littéraux explicites, réduction de l'ambiguïté) sur les langages exotiques, transformant ces derniers en dialectes procéduraux banals.

Dans un langage ésotérique, la surface syntaxique n'est plus simplement un moyen d'exécution, mais un espace artistique à part entière : deux codes peuvent converger rigoureusement vers la même fonction de transition d'état tout en étant séparés par une distance syntaxique énorme. Et c'est justement dans les langages ésothériques que l'on voit la plus grande différence entre un LLM et un humain
